# Password Strength Checker

برنامج بسيط بلغة Python بيفحص قوة كلمة المرور بناءً على 4 شروط:
- الطول (8 أحرف فأكثر)
- وجود رقم
- وجود حرف كبير
- وجود رمز خاص (باستخدام Regular Expressions)

## كيف تشغله

python finalProject.py
## كيف تشغل الاختبارات

pytest TestFinalProject.py


## المفاهيم المستخدمة
Functions, Conditionals, Loops, Regular Expressions (re), Unit Testing (assert)
